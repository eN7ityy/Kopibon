# PDF Metadata Standard for Kavita: The Dr Stein XMP Blueprint

> **Status**: Validated — matches working files in `/mnt/bragi/Kavita/Doujins/dr. stein/`
> **Producer**: pikepdf 10.8.0
> **Last Tested**: 2026-07-28

---

## 0. Critical: Filename Convention

**Kavita's bracket parser interprets `[prefix]` at the start of filenames as metadata tags.** The `[nhentai-XXXXX]` prefix causes Kavita to create a phantom series named `[nhentai`, grouping ALL files with that prefix together and overriding XMP `calibre:series`.

| ❌ Wrong | ✅ Correct |
|---------|----------|
| `[nhentai-662890] Kareshi no Tame ni Nugimasu..pdf` | `Kareshi no Tame ni Nugimasu. [nhentai-662890].pdf` |
| `[nhentai-399759] Gyaru...! 2.pdf` | `Gyaru...! 2 [nhentai-399759].pdf` |

**Rule**: Place `[nhentai-XXXXX]` at the **end** of the filename, not the beginning. This was confirmed by test: files with the bracket at the end display correctly in Kavita; the same files with the bracket at the beginning fail.

## 1. Problem and Findings Summary

### 1.1 Initial Symptoms

PDFs generated by Doujin Downloader (using pdf-lib for docinfo fields only) exhibited three critical failures in Kavita:

| Symptom | Root Cause |
|---------|-----------|
| Title displayed as `[nhentai` instead of actual title | No XMP stream present; Kavita fell back to filename parsing. The `[nhentai-XXXXXX]` bracket prefix in filenames was interpreted as a metadata tag |
| Files with identical `calibre:series` not grouped | pdf-lib cannot write custom XMP namespaces (`calibre:series`, `calibreSI:series_index`). Keywords fallback tokens ignored by Kavita |
| Standalone files invisible in Kavita | pdf-lib's low-level `context.stream()` API for XMP injection created structurally invalid PDFs that pdf-lib tolerated but Kavita rejected |

### 1.2 Failed Approaches

**Approach A — pdf-lib low-level XMP injection** (`context.stream()` + `catalog.set()`):
- Created orphaned Metadata objects (doubling XMP streams on files with existing XMP)
- Made files invisible to Kavita (structurally invalid PDF)
- Required `<?xpacket begin="﻿">` with UTF-8 BOM (`EF BB BF`) — but even with BOM, the PDF structure was corrupt

**Approach B — exiftool sidecar XMP** (`exiftool -xmp<=sidecar.xmp`):
- Merged XMP rather than replacing it (2+ Metadata objects persisted)
- **Critical**: Flattened the nested `rdf:Resource` structure required by Kavita
- `calibre:series` lost its `<rdf:value>` wrapper and nested `<calibreSI:series_index>`
- `-xmp:all=` and `-all:all=` commands left orphaned Metadata streams

### 1.3 Successful Approach — pikepdf

The only working XMP format was found in files processed by **pikepdf 10.8.0** in `/mnt/bragi/Kavita/Doujins/dr. stein/`. These files use a specific nested structure inside `<calibre:series>`:

```xml
<calibre:series rdf:parseType="Resource">
  <rdf:value>Smoking Hypnosis</rdf:value>
  <calibreSI:series_index>8.00</calibreSI:series_index>
</calibre:series>
```

**Key observations**:
1. `calibre:series` MUST use `rdf:parseType="Resource"` with nested `<rdf:value>` and `<calibreSI:series_index>`
2. `<?xpacket begin="﻿">` MUST contain the UTF-8 BOM (bytes `EF BB BF`)
3. The PDF MUST have exactly one `/Type /Metadata` stream referenced from the catalog
4. `dc:title` MUST use `<rdf:Alt>` with `<rdf:li xml:lang="x-default">`
5. `dc:creator` MUST use `<rdf:Seq>` even for a single artist
6. `dc:subject` SHOULD use `<rdf:Bag>` for tags (Kavita reads these as genres)

## 2. Canonical Metadata Specification

### 2.1 Required Namespaces

| Prefix | URI |
|--------|-----|
| `x` | `adobe:ns:meta/` |
| `rdf` | `http://www.w3.org/1999/02/22-rdf-syntax-ns#` |
| `dc` | `http://purl.org/dc/elements/1.1/` |
| `calibre` | `http://calibre-ebook.com/xmp-namespace` |
| `calibreSI` | `http://calibre-ebook.com/xmp-namespace-series-index` |
| `pdfx` | `http://ns.adobe.com/pdfx/1.3/` |
| `prism` | `http://prismstandard.org/namespaces/basic/2.0/` |
| `xmpidq` | `http://ns.adobe.com/xmp/Identifier/qual/1.0/` |

### 2.2 Complete XMP Template

```xml
<?xpacket begin="﻿" id="W5M0MpCehiHzreSzNTczkc9d"?>
<x:xmpmeta xmlns:x="adobe:ns:meta/">
  <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
    <rdf:Description xmlns:dc="http://purl.org/dc/elements/1.1/" rdf:about="">
      <dc:title>
        <rdf:Alt>
          <rdf:li xml:lang="x-default">{{TITLE}}</rdf:li>
        </rdf:Alt>
      </dc:title>
      <dc:creator>
        <rdf:Seq>
{{CREATOR_ITEMS}}
        </rdf:Seq>
      </dc:creator>
      <dc:subject>
        <rdf:Bag>
{{SUBJECT_ITEMS}}
        </rdf:Bag>
      </dc:subject>
      <pdfx:isbn>{{NHENTAI_ID}}</pdfx:isbn>
      <prism:isbn>{{NHENTAI_ID}}</prism:isbn>
{{OPTIONAL_FIELDS}}
    </rdf:Description>
{{SERIES_BLOCK}}
    <rdf:Description xmlns:pdfx="http://ns.adobe.com/pdfx/1.3/" rdf:about="">
      <pdfx:isbn>{{NHENTAI_ID}}</pdfx:isbn>
    </rdf:Description>
    <rdf:Description xmlns:prism="http://prismstandard.org/namespaces/basic/2.0/" rdf:about="">
      <prism:isbn>{{NHENTAI_ID}}</prism:isbn>
    </rdf:Description>
  </rdf:RDF>
</x:xmpmeta>
<?xpacket end="w"?>
```

### 2.3 Optional Fields Template

Add any of these inside the `<rdf:Description>` block:

```xml
      <dc:description>{{DESCRIPTION}}</dc:description>
      <dc:publisher>{{PUBLISHER}}</dc:publisher>
      <dc:language>{{LANGUAGE_CODE}}</dc:language>
      <dc:date>{{ISO_DATE}}</dc:date>
      <pdfx:isbn>{{NHENTAI_ID}}</pdfx:isbn>
      <prism:isbn>{{NHENTAI_ID}}</prism:isbn>
```

**nhentai ID fields**: The nhentai gallery ID is embedded in TWO namespaces for redundancy:
- `pdfx:isbn` — PDF extension namespace (for Kavita/Calibre compatibility)
- `prism:isbn` — PRISM standard namespace (for broader reader compatibility)

Kavita ignores both, but our scanner uses them together with the `nhentai:XXXXX` keyword token for reliable gallery matching.

### 2.4 Series Block Template

Only include if the PDF belongs to a series:

```xml
    <rdf:Description xmlns:calibre="http://calibre-ebook.com/xmp-namespace"
                     xmlns:calibreSI="http://calibre-ebook.com/xmp-namespace-series-index"
                     rdf:about="">
      <calibre:series rdf:parseType="Resource">
        <rdf:value>{{SERIES_NAME}}</rdf:value>
        <calibreSI:series_index>{{VOLUME_NUMBER}}</calibreSI:series_index>
      </calibre:series>
    </rdf:Description>
```

```python
#!/usr/bin/env python3
"""PDF XMP injector using pikepdf — Dr Stein compatible format."""

import sys
import json
import pikepdf
from pikepdf import Pdf, Dictionary, Name, Stream

# ─── Constants ─────────────────────────────────────────────────────────────

XMP_HEADER = '<?xpacket begin="\ufeff" id="W5M0MpCehiHzreSzNTczkc9d"?>\n'
XMP_FOOTER = '\n<?xpacket end="w"?>'

def esc_xml(s: str) -> str:
    """Escape special XML characters."""
    return s.replace("&", "&").replace("<", "<").replace(">", ">").replace('"', """)

def build_xmp(title: str, creators: list[str], tags: list[str],
              nhentai_id: int = None,
              series_name: str = None, series_index: float = None,
              description: str = None, publisher: str = None,
              language: str = None, date: str = None) -> str:
    """
    Build a complete XMP metadata packet in the Dr Stein format.
    
    Args:
        title: Chapter/gallery title (dc:title)
        creators: List of artist/author names (dc:creator)
        tags: List of genre tags (dc:subject)
        series_name: Calibre series name (optional)
        series_index: Volume number as float (optional)
        description: Summary text (optional)
        publisher: Publisher name (optional)
        language: ISO 639-1 language code (optional)
        date: ISO 8601 date string (optional)
    
    Returns:
        Complete XMP XML string
    """
    creator_items = "\n".join(f"          <rdf:li>{esc_xml(c)}</rdf:li>" for c in creators)
    tag_items = "\n".join(f"          <rdf:li>{esc_xml(t)}</rdf:li>" for t in tags)
    
    optional = ""
    if description:
        optional += f"      <dc:description>{esc_xml(description)}</dc:description>\n"
    if publisher:
        optional += f"      <dc:publisher>{esc_xml(publisher)}</dc:publisher>\n"
    if language:
        optional += f"      <dc:language>{esc_xml(language)}</dc:language>\n"
    if date:
        optional += f"      <dc:date>{esc_xml(date)}</dc:date>\n"
    
    series_block = ""
    if series_name and series_index is not None:
        series_block = f"""
    <rdf:Description xmlns:calibre="http://calibre-ebook.com/xmp-namespace"
                     xmlns:calibreSI="http://calibre-ebook.com/xmp-namespace-series-index"
                     rdf:about="">
      <calibre:series rdf:parseType="Resource">
        <rdf:value>{esc_xml(series_name)}</rdf:value>
        <calibreSI:series_index>{series_index:.2f}</calibreSI:series_index>
      </calibre:series>
    </rdf:Description>"""
    
    return f"""{XMP_HEADER}<x:xmpmeta xmlns:x="adobe:ns:meta/">
  <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
    <rdf:Description xmlns:dc="http://purl.org/dc/elements/1.1/" rdf:about="">
      <dc:title>
        <rdf:Alt>
          <rdf:li xml:lang="x-default">{esc_xml(title)}</rdf:li>
        </rdf:Alt>
      </dc:title>
      <dc:creator>
        <rdf:Seq>
{creator_items}
        </rdf:Seq>
      </dc:creator>
      <dc:subject>
        <rdf:Bag>
{tag_items}
        </rdf:Bag>
      </dc:subject>
    nhentai_id_block = ""
    if nhentai_id is not None:
        nhentai_id_block = f"""
    <rdf:Description xmlns:pdfx="http://ns.adobe.com/pdfx/1.3/" rdf:about="">
      <pdfx:isbn>{nhentai_id}</pdfx:isbn>
    </rdf:Description>
    <rdf:Description xmlns:prism="http://prismstandard.org/namespaces/basic/2.0/" rdf:about="">
      <prism:isbn>{nhentai_id}</prism:isbn>
    </rdf:Description>"""

    return f"""{XMP_HEADER}<x:xmpmeta xmlns:x="adobe:ns:meta/">
  <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
    <rdf:Description xmlns:dc="http://purl.org/dc/elements/1.1/" rdf:about="">
      <dc:title>
        <rdf:Alt>
          <rdf:li xml:lang="x-default">{esc_xml(title)}</rdf:li>
        </rdf:Alt>
      </dc:title>
      <dc:creator>
        <rdf:Seq>
{creator_items}
        </rdf:Seq>
      </dc:creator>
      <dc:subject>
        <rdf:Bag>
{tag_items}
        </rdf:Bag>
      </dc:subject>
      <pdfx:isbn>{nhentai_id or ''}</pdfx:isbn>
      <prism:isbn>{nhentai_id or ''}</prism:isbn>
{optional}    </rdf:Description>{series_block}{nhentai_id_block}
  </rdf:RDF>
</x:xmpmeta>{XMP_FOOTER}"""


def extract_existing_metadata(pdf_path: str) -> dict:
    """Extract existing metadata for archival before nuking."""
    pdf = Pdf.open(pdf_path)
    info = {}
    
    try:
        with pdf.open_metadata() as meta:
            # Extract Dublin Core
            for field in ['dc:title', 'dc:creator', 'dc:subject', 
                         'dc:description', 'dc:publisher', 'dc:language']:
                try:
                    val = getattr(meta, field.replace('dc:', ''), None)
                    if val: info[field] = val
                except: pass
            
            # Extract Calibre
            try: info['calibre:series'] = meta.get('calibre:series')
            except: pass
            try: info['calibreSI:series_index'] = meta.get('calibreSI:series_index')
            except: pass
    except:
        # Fallback: extract from docinfo
        if pdf.docinfo:
            for key in ['/Title', '/Author', '/Subject', '/Keywords']:
                if key in pdf.docinfo:
                    info[key] = str(pdf.docinfo[key])
    
    pdf.close()
    return info


def nuke_metadata(pdf: Pdf):
    """Completely remove all metadata streams and docinfo from a PDF."""
    # Remove XMP metadata stream from catalog
    if Name.Metadata in pdf.Root:
        del pdf.Root[Name.Metadata]
    
    # Clear all streams containing XMP by type
    to_delete = []
    for objnum, obj in pdf.objects.items():
        if isinstance(obj, Stream) or isinstance(obj, Dictionary):
            try:
                if Name.Type in obj and obj[Name.Type] == Name.Metadata:
                    to_delete.append(objnum)
            except: pass
    
    for objnum in to_delete:
        del pdf.objects[objnum]
    
    # Clear docinfo
    if pdf.docinfo:
        for key in list(pdf.docinfo.keys()):
            del pdf.docinfo[key]


def inject_xmp(pdf: Pdf, xmp_xml: str):
    """Inject a fresh XMP metadata stream into the PDF."""
    xmp_bytes = xmp_xml.encode('utf-8')
    metadata_stream = Stream(pdf, xmp_bytes)
    metadata_stream[Name.Type] = Name.Metadata
    metadata_stream[Name.Subtype] = Name.XML
    
    pdf.Root[Name.Metadata] = pdf.make_indirect(metadata_stream)


def process_pdf(input_path: str, output_path: str, metadata: dict):
    """
    Full pipeline: open → extract → nuke → inject → save.
    
    Args:
        input_path: Source PDF file
        output_path: Destination PDF file
        metadata: Dict with keys: title, creators, tags,
                  optional: series_name, series_index,
                  description, publisher, language, date
    """
    # Open
    pdf = Pdf.open(input_path)
    
    # Extract (optional — for logging/backup)
    # existing = extract_existing_metadata(input_path)
    
    # Nuke
    nuke_metadata(pdf)
    
    # Build XMP
    xmp = build_xmp(
        title=metadata.get('title', 'Untitled'),
        creators=metadata.get('creators', ['Unknown']),
        tags=metadata.get('tags', []),
        series_name=metadata.get('series_name'),
        series_index=metadata.get('series_index'),
        description=metadata.get('description'),
        publisher=metadata.get('publisher'),
        language=metadata.get('language'),
        date=metadata.get('date')
    )
    
    # Inject
    inject_xmp(pdf, xmp)
    
    # Save
    pdf.save(output_path)
    pdf.close()


def validate_xmp(pdf_path: str) -> dict:
    """Validate that a PDF has correct Dr Stein format XMP."""
    import re
    
    with open(pdf_path, 'rb') as f:
        raw = f.read()
    
    result = {
        'has_xmp': b'x:xmpmeta' in raw,
        'has_bom': b'xpacket begin="\xef\xbb\xbf"' in raw,
        'metadata_count': len(re.findall(b'/Type /Metadata', raw)),
    }
    
    # Check for rdf:value inside calibre:series
    cs_match = re.search(
        rb'<calibre:series[^>]*>[\s\S]*?<rdf:value>([^<]+)</rdf:value>[\s\S]*?</calibre:series>',
        raw
    )
    if cs_match:
        result['calibre_series'] = cs_match.group(1).decode('utf-8').strip()
        result['has_rdf_value'] = True
    else:
        result['has_rdf_value'] = False
    
    # Check for calibreSI:series_index
    si_match = re.search(
        rb'<calibreSI:series_index>([^<]+)</calibreSI:series_index>',
        raw
    )
    result['has_series_index'] = si_match is not None
    if si_match:
        result['series_index'] = float(si_match.group(1))
    
    return result


# ─── CLI Entry Point ──────────────────────────────────────────────────────

if __name__ == '__main__':
    if len(sys.argv) < 3:
        print("Usage: xmp-inject.py <input.pdf> <output.pdf> <metadata.json>")
        sys.exit(1)
    
    input_path = sys.argv[1]
    output_path = sys.argv[2]
    metadata = json.loads(sys.argv[3]) if len(sys.argv) > 3 else {}
    
    process_pdf(input_path, output_path, metadata)
    
    # Validate output
    result = validate_xmp(output_path)
    print(json.dumps(result, indent=2))
```

```typescript
import { spawn } from 'child_process'
import { join } from 'path'

function injectXmpWithPikepdf(
  pdfPath: string,
  outputPath: string,
  metadata: {
    title: string
    creators: string[]
    tags: string[]
    nhentaiId?: number
    seriesName?: string
    seriesIndex?: number
    description?: string
    publisher?: string
    language?: string
    date?: string
  }
): Promise<{ success: boolean; validation?: Record<string, unknown>; error?: string }> {
  return new Promise((resolve) => {
    const script = join(__dirname, 'xmp-inject.py')
    const args = [script, pdfPath, outputPath, JSON.stringify({
      title: metadata.title,
      creators: metadata.creators,
      tags: metadata.tags,
      nhentai_id: metadata.nhentaiId,
      series_name: metadata.seriesName,
      series_index: metadata.seriesIndex,
      description: metadata.description,
      publisher: metadata.publisher,
      language: metadata.language,
      date: metadata.date
    })]
    
    const proc = spawn('python3', args)
    let stdout = ''
    let stderr = ''
    
    proc.stdout.on('data', (d) => { stdout += d })
    proc.stderr.on('data', (d) => { stderr += d })
    
    proc.on('close', (code) => {
      if (code === 0) {
        try {
          const validation = JSON.parse(stdout)
          resolve({ success: true, validation })
        } catch {
          resolve({ success: true })
        }
      } else {
        resolve({ success: false, error: stderr || `Exit code ${code}` })
      }
    })
    
    proc.on('error', (err) => {
      resolve({ success: false, error: err.message })
    })
  })
}
```

## 4. New PDF Ingestion Strategy

### 4.1 Golden Path

```
nhentai API → download images → pdf-lib generate PDF (docinfo only)
  → pikepdf strip all docinfo → pikepdf inject XMP (Dr Stein format)
  → save final PDF → Kavita scan
```

### 4.2 Integration Points

**In [`download-pdf.worker.ts`](src/main/services/download-pdf.worker.ts):**
- After pdf-lib generates the PDF, write it to a temp path
- Call pikepdf to strip docinfo + inject XMP
- Move the final PDF to the library directory

**In [`metadata.worker.ts`](src/main/services/metadata.worker.ts):**
- When updating library metadata (series assignment, title edit):
  - Load the existing PDF
  - Extract current metadata for preservation
  - Call pikepdf with the merged metadata

### 4.3 Data Mapping

| Source Field | XMP Field | Notes |
|-------------|-----------|-------|
| `gallery.id` | `pdfx:isbn`, `prism:isbn` | nhentai gallery ID for matching |
| `gallery.title.pretty` | `dc:title` | Use as-is |
| Artist tags (type=artist) | `dc:creator` | Comma-separated in `dc:creator/rdf:Seq/rdf:li` |
| All tag names | `dc:subject` | Each tag as `rdf:li` in `dc:subject/rdf:Bag` |
| Language tag | `dc:language` | Map to ISO 639-1 code |
| Upload date | `dc:date` | ISO 8601 format |
| `seriesName` (DB) | `calibre:series/rdf:value` | Only if assigned |
| `seriesIndex` (DB) | `calibreSI:series_index` | Only if assigned |
| `publisher` (DB) | `dc:publisher` | Only if set |
| `description` (DB) | `dc:description` | Only if set |

## 5. Legacy PDF Remediation Plan

### 5.1 Batch Processing Script

```python
#!/usr/bin/env python3
"""Batch remediate all PDFs in a directory to Dr Stein XMP format."""

import os
import sys
import json
from pathlib import Path
from xmp_inject import process_pdf, extract_existing_metadata, build_xmp

def remediate_library(library_root: str, dry_run: bool = True):
    """
    Walk library directory, extract metadata, and rewrite XMP.
    
    Args:
        library_root: Path to Kavita library root
        dry_run: If True, only print what would be done
    """
    errors = []
    skipped = []
    processed = []
    
    for pdf_path in Path(library_root).rglob('*.pdf'):
        pdf_str = str(pdf_path)
        temp_path = pdf_str + '.tmp.pdf'
        
        try:
            # Extract existing metadata
            existing = extract_existing_metadata(pdf_str)
            
            # Determine metadata from filename + existing
            filename = pdf_path.stem
            title = existing.get('dc:title') or filename
            
            # Try to extract series/index from filename
            # Pattern: [nhentai-XXXXXX] Title Ch. N
            import re
            ch_match = re.match(r'.*\bCh\.\s*(\d+(?:[.-]\d+)?)\b', filename)
            series_index = None
            if ch_match:
                series_index = float(ch_match.group(1).replace('-', '.'))
            
            creators = [existing.get('dc:creator', 'Unknown')]
            if isinstance(creators, str):
                creators = [c.strip() for c in creators.split(',')]
            
            tags_raw = existing.get('dc:subject', '')
            if isinstance(tags_raw, list):
                tags = tags_raw
            elif isinstance(tags_raw, str):
                tags = [t.strip() for t in tags_raw.split(',') if t.strip()]
            else:
                tags = []
            
            series_name = existing.get('calibre:series')
            
            if dry_run:
                print(f"[DRY RUN] {pdf_path.name}")
                print(f"  Title: {title}")
                print(f"  Creators: {creators}")
                print(f"  Series: {series_name} #{series_index}" if series_name else "  (no series)")
                continue
            
            # Process
            metadata = {
                'title': title,
                'creators': creators,
                'tags': tags,
            }
            if series_name:
                metadata['series_name'] = series_name
            if series_index is not None:
                metadata['series_index'] = series_index
            
            process_pdf(pdf_str, temp_path, metadata)
            
            # Atomic replace
            os.replace(temp_path, pdf_str)
            processed.append(pdf_str)
            print(f"[OK] {pdf_path.name}")
            
        except Exception as e:
            errors.append(f"{pdf_path.name}: {e}")
            print(f"[ERROR] {pdf_path.name}: {e}")
            # Clean up temp file
            if os.path.exists(temp_path):
                os.remove(temp_path)
    
    print(f"\nSummary: {len(processed)} processed, {len(skipped)} skipped, {len(errors)} errors")
    if errors:
        print("\nErrors:")
        for e in errors:
            print(f"  - {e}")

if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("Usage: remediate.py <library_root> [--apply]")
        sys.exit(1)
    
    root = sys.argv[1]
    dry_run = '--apply' not in sys.argv
    remediate_library(root, dry_run=dry_run)
```

### 5.2 Edge Cases

| Case | Handling |
|------|---------|
| Password-protected PDF | Catch `pikepdf.PasswordError`, log, skip |
| Malformed PDF | Catch `pikepdf.PdfError`, log, skip |
| File in use | Use temp file + atomic rename (`os.replace`) |
| No existing metadata | Derive from filename patterns |
| CJK characters in title/artist | pikepdf handles UTF-8 natively |

## 6. Mapping to Kavita's Behavior

| Kavita Field | XMP Field | Priority |
|-------------|-----------|----------|
| **Series** | `calibre:series/rdf:value` | XMP takes precedence over directory grouping |
| **Title** | `dc:title/rdf:Alt/rdf:li[@xml:lang="x-default"]` | XMP overrides filename |
| **Volume/Number** | `calibreSI:series_index` (inside `calibre:series`) | Must be nested in rdf:Resource |
| **Writer/Artist** | `dc:creator/rdf:Seq/rdf:li` | Supports multiple creators |
| **Genres** | `dc:subject/rdf:Bag/rdf:li` | Each tag becomes a genre |
| **Summary** | `dc:description` | Displayed in details panel |
| **Publisher** | `dc:publisher` | Displayed in details panel |
| **Language** | `dc:language` | ISO 639-1 code |
| **Release Date** | `dc:date` | ISO 8601 format |
| **ISBN** | `pdfx:isbn` or `prism:isbn` | Can use nhentai ID |

### 6.1 Priority Rules

1. **XMP `dc:title` > filename** — If valid XMP exists, Kavita ignores the filename entirely for title
2. **XMP `calibre:series` > directory name** — Series grouping uses XMP first, falls back to parent directory name
3. **`calibreSI:series_index` REQUIRES `calibre:series`** — Volume number is ignored without a series parent
4. **All `calibre:series` values must be byte-identical** across files for Kavita to group them
